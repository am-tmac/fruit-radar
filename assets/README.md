# 应用图标

- `app-icon.png` — 1024×1024 图标源（满幅白底，无透明边距）
- 源素材是用户提供的「彩虹飘带苹果」logo（350×350，模糊位图）
- 处理流程：先平滑放大到 2048 → 按实测调色板量化（
  `#62BB47` / `#FCBA27` / `#F6821F` / `#E03A3E` / `#963D97`）→ 再降采样到 1024，
  得到干净硬边且形状忠实的成品
- 重新生成整套图标：

  ```bash
  pnpm tauri icon assets/app-icon.png
  ```

- 注意：图形必须**满幅、无透明边距**。macOS 26 会在图标后垫自己的底板，自留边距会出现「双层白」的灰缝。
